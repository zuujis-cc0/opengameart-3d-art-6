Low-poly 3D models of potion bottles, one unfilled, the others filled with liquids of multiple colors.

The models are deliberately primitive to imitate the style of the bottles that appear in Ocarina of Time - those used by Link to catch insects or store potions - although they also are deliberately made to look a little different to avoid too close an imitation.

Each potion has an extended neck to provide plenty of space for a character's hand to hold the potion by.

The models are given in .glb file format, which is the recommended file format for 3D models to be imported into the Godot game engine.

There should be enough colors for different potion types in a game, but if another color is needed, go into the source Blender file provided, then in the Shader Editor of the potion object edit the "Custom" color node as desired, then export the object to .glb.

Enjoy!
