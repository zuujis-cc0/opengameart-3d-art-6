N64 Sign
========

A 3D wooden sign model that imitates those that appear in Super Mario 64 or Ocarina of Time.

This is a low-poly and altogether low-definition 3D model in a retro Nintendo 64 style. Example uses would be sources of player information in indie horror games or retro RPGs.

The sign comes with textures that are deliberately low-resolution and quite primitive-looking. The text on the sign is just a jumble of lines that only look like real text and have no meaning. The intention is that a player would interact with this sign and then be presented with a window containing actual legible text, like the signs in the aforementioned Nintendo 64 games.

The sign model continues slightly below its origin in 3D space so that it can be embedded in uneven ground without appearing to float.

This submission contains the sign exported into .glb and .obj file formats, the original texture images, the source Blender file in which it was modelled, alternative texture images and an Aseprite file from which the textures are sourced.

Enjoy!
